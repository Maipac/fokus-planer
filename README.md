# Fokus

Ein einfacher, responsiver Aufgabenplaner mit drei Seiten: Übersicht, Aufgaben und Statistik. Aufgaben lassen sich anlegen, abhaken, filtern und löschen. Die Daten werden ausschließlich im lokalen Speicher des Browsers gespeichert.

## Starten

`dist/index.html` im Browser öffnen oder den Ordner `dist` mit einem lokalen Webserver bereitstellen, zum Beispiel mit `python3 -m http.server 8000 --directory dist`.

Keine Installation oder externen Abhängigkeiten erforderlich.
